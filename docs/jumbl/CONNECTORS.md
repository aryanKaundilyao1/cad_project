# Jumbl Workspace — Integrations & Connectors

## Settings -> Integrations
A dedicated interface for third-party tools. No fake integrations. Features that are not ready must be labeled "COMING SOON".

## Connector Interface
- `Authentication` (Prefer OAuth)
- `Import / Export`
- `Sync / Webhook`
- `Mapping` (External -> Canonical Schema)

## Data Combining
Jumbl can use JAS-sourced data, connect their own HubSpot CRM, or combine both. All external data normalizes through the Canonical Entity and Lead DNA models.
